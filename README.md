# Мабетэк · Закупки

Личный помощник по закупкам для хабаровской базы. Рабочая копия разработки. Статус приёмки и ограничения приведены в [отчёте](reports/status.md).

## Работа в Telegram

Откройте личный чат [Мабетэк · Закупки](https://t.me/mabetek_tenders_bot). Команда `/status` показывает время последнего обхода каждого источника, контакт с Mac и размер очереди. Для извещений с точным временем публикации отдельно видны число доставленных из опубликованных за последние семь дней, число доставленных за 30 минут и P95 этой группы. Время с суффиксом Z указано по UTC. Команда `/check` запрашивает обход с учётом интервала и дневного бюджета. Последние извещения доступны по `/inbox`, смысловая подборка — по `/semantic`.

Команда `/sources` открывает ссылки на публичные каталоги и подсказывает, как искать вручную. Выбирайте Хабаровский край по месту исполнения и действующий приём заявок или предложений. Начните с отдельных запросов «выгрузка вагонов», «железнодорожный тупик», «перевалка» и «склад с подъездным путём». Место исполнения и обязательные услуги проверяйте в документации закупки.

Автоматические уведомления о новых закупках и `/inbox` требуют совпадения по услуге и явного указания Хабаровска как места работ. Бот показывает основание вместе с уведомлением. Точное место из прочитанного оригинала имеет приоритет перед заголовком каталога. Если место установить не удалось, карточка остаётся в архиве для смыслового поиска по запросу.

Чтобы открыть извещение ЕИС, карточку РЖД или отдельный лот Росэлторга, отправьте команду `/watch` и ссылку на оригинал одним сообщением. Уведомления о закупках ЕИС также содержат кнопку открытия карточки. Если Cloudflare не может открыть поддерживаемое извещение ЕИС или лот Росэлторга, бот ставит его в очередь Mac. При выпуске КП по извещению ЕИС агент повторно читает оригинал перед отправкой. При изменении условий, срока или статуса бот останавливает отправку.

Кнопка «Документы» открывает доступные приложения. Кнопка «Разобрать» запрашивает анализ. В «Уточнить условия» владелец указывает собственные ставки и условия, проверяет сводку, затем подтверждает выпуск PDF. Предложение приходит владельцу для проверки и ручной подачи.

## Компоненты

- TypeScript Worker принимает Telegram webhook под секретом, обрабатывает команды владельца, очереди, уведомления и расписание. Расписание рассчитано на интервал 15 минут.
- D1 хранит исходные извещения, версии процедур, доказательства, ответы, результаты и задачи с арендой. Поле региона отделено от места исполнения. Для покупки без установленного номера лота показывается процедура.
- Локальный Python-агент использует исходящий HTTPS. Для зарегистрированной задачи разбора он применяет словарь, для задачи выпуска формирует PDF по проверенной сводке. Рабочее место поддерживает ручной импорт отдельных оригиналов и приложений.
- В комплекте нет платных API или автоматического включения платного тарифа.

## Проверки

Из корня этого репозитория, Python 3.12 и Node.js 22:

    python3 -m pip install -r agent/requirements.txt
    python3 -m unittest discover -s tests
    npm ci
    npm test
    npm run typecheck
    python3 -m agent.sources

Последняя команда обращается к реальным витринам и указывает время, HTTP-ошибку либо факт загрузки страницы. Для подтверждения адаптера требуется прочитать содержательную выдачу и оригинал закупки.

## Локальная работа

    python3 -m agent.local --db .private/demo.sqlite import examples/rzd-control.json
    python3 -m agent.local --db .private/demo.sqlite inbox
    python3 -m agent.local --db .private/demo.sqlite show 1
    python3 -m agent.local --db .private/demo.sqlite answer 1 1 examples/terms-demo.json
    python3 -m agent.local --db .private/demo.sqlite preview 1

Номер записи и редакция выводятся при импорте. Дополнительные позиционные аргументы команды import — файлы PDF, DOCX, XLSX и ZIP. На сканах используется локальный OCR при наличии русских и английских данных Tesseract. Старые DOC/XLS дают явную ошибку формата. Фрагменты привязаны к странице, абзацу или ячейке. Команда backup создаёт приватную резервную копию SQLite.

Для выпуска из локального рабочего места команда issue принимает номер записи, --approve-digest со значением из preview, --template с путём к утверждённому PDF и имя нового выходного файла. Оператор сверяет срок и условия с оригиналом. Контрольный пример предназначен только для разработки. Демонстрационные ставки не являются ценами компании.

## Ресурсы и восстановление

Репозиторий — https://github.com/stepankovner/mabetek-tenders. Telegram — https://t.me/mabetek_tenders_bot. Имя отдельной базы D1 — mabetek-tenders. Её идентификатор записан в wrangler.toml. Выпуск production требует завершения проверок из отчёта.

После проверки аккаунта на Free миграции применяются Wrangler командой npx wrangler d1 migrations apply mabetek-tenders --remote. Секреты Worker задаются через закрытые поля BOT_TOKEN, WEBHOOK_SECRET, AGENT_KEY. Токен Telegram на Mac хранится в связке «Вход» под именем mabetek-tenders.telegram. В случае утраты контролировать того же бота через официальный BotFather, заменить токен Worker и повторно установить webhook с секретом. Ключ агента меняется в Worker и приватной конфигурации Mac одновременно.

Привязка владельца использует одноразовый код с SHA-256 в таблице pairing и expires в секундах UTC; бот принимает /start с этим кодом только в личном чате. В таблице owner может быть одна привязка. Скомпрометированный неиспользованный код следует удалить из pairing. Привязка и изменение ключей требуют доступа администратора проекта.

Конфигурация агента — файл agent.json с правами 0600 в ~/Library/Application Support/mabetek-tenders, поля worker (полный HTTPS-адрес нового Worker), key (отдельный секрет агента), template (путь к утверждённому фирменному PDF). После настройки python3 -m agent.daemon --once проверяет обмен, python3 -m agent.daemon --install устанавливает пользовательский LaunchAgent. После входа в macOS он запускается автоматически. Сбой или сон видны в /status по времени последнего контакта.

Компилятор TypeScript закреплён в package-lock.json и устанавливается через npm ci. Команда npm test запускает также интеграционные проверки Worker с локальным SQLite и тестовыми транспортами. Переменная TSC позволяет выбрать другой установленный компилятор. Официальные данные Tesseract rus.traineddata и eng.traineddata устанавливаются в .private/tessdata или указываются через TESSDATA_PREFIX. При скане проверяются четыре ориентации страницы. Для выдачи оригинала с фирменной шапкой и подвалом приватный исходник нужен только на Mac.

## Проверенный сценарий в Telegram

В личном чате владельца /status показывает доступность источников и время последнего контакта Mac. Команда /watch со ссылкой на оригинал РЖД создаёт карточку. После ввода условий и сверки суммы кнопка «Сформировать КП» ставит документ в очередь Mac. Статус реальных испытаний и ограничения приведены в reports/status.md.

На подготовленном Mac запустите Install-Mac-Agent.command из папки проекта. При запуске из клона используйте zsh Install-Mac-Agent.command. Установщику нужны фирменный PDF, Python с зависимостями и запись mabetek-tenders.agent в связке ключей текущего пользователя. Установка проверяет соединение с Worker и регистрирует LaunchAgent.

Перед установкой из отдельного клона установите браузерную зависимость командой npm ci. Для обхода динамических каталогов агент использует установленный Google Chrome. Фоновый процесс работает после входа в macOS и может выполнять обход с выключенным дисплеем.

## Обновление облачного обработчика

Publish-Worker.command выполняет обе группы тестов, затем публикует обработчик mabetek-zakupki. Используется обычная авторизация Wrangler для существующего аккаунта. Результат публикации сохраняется в .private/deploy-latest.log. Результаты браузерных проверок приведены в reports/source-coverage.md.

Для смысловой подборки предусмотрен Workers AI binding AI и команда /semantic. Перед включением привязки следует подтвердить Workers Free в аккаунте. До включения модель не вызывается. Миграция 0003 добавляет таблицы для кэша и рейтингов, безопасна для повторного выполнения. Без калибровки на размеченной выборке сходство используется только для просмотра подборки.

Локальная Qwen3-8B-Q4_K_M запускается через llama-completion при анализе приложений на обновлённом агенте. Install-Local-Model.command скачивает контрольный файл с официальной страницы Qwen, сверяет SHA-256 и устанавливает llama.cpp через Homebrew при необходимости. Размер модели 5 027 783 488 байт. Цитаты сверяются посимвольно с извлечённым фрагментом. В отсутствие модели остаётся доступен обычный анализ приложений.

В документах извещения РЖД 32616584495 доступен отдельный Word-бланк технического предложения. После ввода условий откройте «Данные для формы заказчика», затем «Получить черновик формы Word». Бот переносит однозначно указанную процентную ставку. Для другого режима поле остаётся пустым. Если бот использовал ранее проверенную копию, он указывает это в подписи. Отдельные сведения об участнике, персонале и согласия проверяет и оформляет владелец.

## Восстановление после сбоев

Кандидат сохраняется в локальную очередь в той же транзакции SQLite, что и наблюдение каталога. Агент повторяет передачу независимо от того, осталась ли карточка в текущей выдаче. Подтверждения Worker сохраняются отдельно; потеря ответа не удаляет задачу. Повторная передача дедуплицируется в облаке. Ошибка одного источника не останавливает передачу остальных. Для временных ошибок действует нарастающая задержка, для HTTP 429 учитывается Retry-After.

После входа в macOS launchd поддерживает фоновую службу. При обычной сети /status показывает версию Mac, размер и возраст локальной очереди, ошибки чтения баз и время последней резервной копии. При отсутствии контакта более 20 минут облачный опрос отправляет одно предупреждение за эпизод, после восстановления — сообщение о возобновлении. При расписании раз в 15 минут предупреждение ожидается через 20–35 минут; пауза владельца не вызывает его. Штатный установщик удерживает Mac от автоматического сна от сети на время работы агента. Дисплей может выключаться. Выключение Mac, выход из учётной записи и закрытие крышки при обычной работе ноутбука могут прервать сбор.

Агент каждый час проверяет наличие ежедневных копий SQLite в ~/Library/Application Support/mabetek-tenders/backups. Копии создаются приватными, проходят integrity_check; для каждой базы сохраняются последние семь ежедневных снимков. Проверенная ручная копия создаётся командой python3 -m agent.local --db ПУТЬ_К_БАЗЕ backup НОВЫЙ_ФАЙЛ. Для восстановления остановите службу, сохраните повреждённую базу отдельно, замените её проверенной копией и снова запустите службу. Повторная передача после восстановления безопасна благодаря облачной дедупликации. Это локальные копии на том же диске; потеря самого диска требует отдельной внешней копии.

Оба реестра ЕИС на Mac читают свежую общую выдачу и ведут отдельный поиск по профильным услугам. В реестре закупок дополнительно проверяется ИНН РЖД. Профильные результаты запрашиваются от новых к старым по дате размещения. Карточки с явно истёкшим сроком отсеиваются, даже если реестр всё ещё показывает приём заявок. В общей выдаче агент повторяет первые две страницы каждый цикл и читает одну более глубокую, если она есть. В профильной выдаче он читает первую страницу и одну страницу продолжения за цикл. Сбой на странице сохраняется для повторной попытки, следующие страницы остаются в обходе. Курсоры и страницы для повторной проверки сохраняются между запусками. Частичный обход виден в `/status`. Для автоматического уведомления требуется совпадение по услугам и подтверждение Хабаровска как места работ.

РТС продолжает возвращать 503 Anti-DDoS. Полный охват площадок и приёмочные показатели поиска пока не подтверждены. Результаты проверок записаны в reports/status.md.

Карточки ЕИС по 44-ФЗ и 223-ФЗ открываются через `/watch`. Фоновая очередь проверяет приложения у отобранных карточек, включая выборку с общими заголовками, и повторно проверяет отслеживаемые карточки. Mac запускает по одной проверке не чаще одного раза в две минуты. Непроверенные задачи сохраняются и обрабатываются раньше плановых повторных проверок в той же очереди. В статусе отображается возраст старейшей непроверенной задачи. Уведомление по приложению требует подтверждённых работ и места в Хабаровске. Если адреса расходятся, бот не считает совпадение подтверждённым.

«Разобрать» показывает цитаты с именами файлов и местом в документе, распознанные формы и ограничения разбора. Поддерживаются PDF, DOC, DOCX, XLSX и ZIP. Форматы вроде 7z сверяются по контрольной сумме и помечаются как неподдерживаемые для чтения. Лимит одной проверки — 12 файлов, до 12 МБ на файл и 40 МБ суммарно. Неполная проверка видна в статусе и блокирует выдачу КП и заполненного бланка для ЕИС и секции РЖД. Для лотов Росэлторга доступна сверка самого извещения, комплект приложений проверяется вручную.

Если изменились срок, состав приложений или содержимое файла по той же ссылке, бот создаёт новую редакцию. Старые ответы и КП остаются в истории, новые условия надо подтвердить в новой редакции. Перед выдачей КП или заполненного бланка Mac снова проверяет оригинал и хеши файлов.

После заполнения условий кнопка «Данные для формы заказчика» показывает найденные бланки. Агент переносит подтверждённые значения в однозначные пустые ячейки DOCX и XLSX. Заполненные, неоднозначные и защищённые поля остаются для ручной проверки. В Excel сохраняются стили и формулы. Черновик приходит в личный чат вместе с перечнем перенесённых и ручных полей. Документы заказчику бот не подаёт.
