# Мабетэк · Закупки

Личный помощник по закупкам для хабаровской базы. Рабочая копия разработки. Статус приёмки и ограничения приведены в [отчёте](reports/status.md).

## Работа в Telegram

Откройте личный чат [Мабетэк · Закупки](https://t.me/mabetek_tenders_bot). Команда `/status` показывает время последнего обхода каждого источника, контакт с Mac и размер очереди. Время с суффиксом Z указано по UTC. Команда `/check` запрашивает обход с учётом интервала и дневного бюджета. Последние извещения доступны по `/inbox`, смысловая подборка — по `/semantic`.

Для карточки РЖД или отдельного лота Росэлторга отправьте `/watch` и ссылку на оригинал одним сообщением. Если Cloudflare не может открыть лот Росэлторга, бот ставит его в очередь. Включённый Mac после входа пользователя проверяет очередь и возвращает результат в тот же чат. Время ожидания зависит от доступности Mac и самой площадки. После установки агента окно Терминала можно закрыть.

Кнопка «Документы» открывает доступные приложения. Кнопка «Разобрать» запрашивает анализ. В «Уточнить условия» владелец указывает собственные ставки и условия, проверяет сводку, затем подтверждает выпуск PDF. Предложение приходит владельцу для проверки и ручной подачи.

## Компоненты

- TypeScript Worker принимает Telegram webhook под секретом, обрабатывает команды владельца, очереди, уведомления и расписание. Расписание рассчитано на интервал 15 минут.
- D1 хранит исходные извещения, версии процедур, доказательства, ответы, результаты и задачи с арендой. Поле региона отделено от места исполнения. Для покупки без установленного номера лота показывается процедура.
- Локальный Python-агент использует исходящий HTTPS. Для зарегистрированной задачи разбора он применяет словарь, для задачи выпуска формирует PDF по проверенной сводке. Рабочее место поддерживает ручной импорт отдельных оригиналов и приложений.
- В комплекте нет платных API или автоматического включения платного тарифа.

## Проверки

Из корня этого репозитория, Python 3.12 и Node.js 22:

    python3 -m pip install -r agent/requirements.txt
    python3 -m unittest discover -s tests
    node --test tests/*.mjs
    python3 -m agent.sources

Последняя команда обращается к реальным витринам и указывает время, HTTP-ошибку либо факт загрузки страницы. Для подтверждения адаптера требуется прочитать содержательную выдачу и оригинал закупки.

## Локальная работа

    python3 -m agent.local --db .private/demo.sqlite import examples/rzd-control.json
    python3 -m agent.local --db .private/demo.sqlite inbox
    python3 -m agent.local --db .private/demo.sqlite show 1
    python3 -m agent.local --db .private/demo.sqlite answer 1 1 examples/terms-demo.json
    python3 -m agent.local --db .private/demo.sqlite preview 1

Номер записи и редакция выводятся при импорте. Дополнительные позиционные аргументы команды import — файлы PDF, DOCX, XLSX и ZIP. На сканах используется локальный OCR при наличии русских и английских данных Tesseract. Старые DOC/XLS дают явную ошибку формата. Фрагменты привязаны к странице, абзацу или ячейке. Команда backup создаёт приватную резервную копию SQLite.

Для выпуска из локального рабочего места команда issue принимает номер записи, --approve-digest со значением из preview, --template с путём к утверждённому PDF и имя нового выходного файла. Оператор сверяет срок и условия с оригиналом. Контрольный пример предназначен только для разработки. Демонстрационные ставки не являются ценами компании.

## Ресурсы и восстановление

Репозиторий — https://github.com/stepankovner/mabetek-tenders. Telegram — https://t.me/mabetek_tenders_bot. Имя отдельной базы D1 — mabetek-tenders. Её идентификатор записан в wrangler.toml. Выпуск production требует завершения проверок из отчёта.

После проверки аккаунта на Free миграции применяются Wrangler командой npx wrangler d1 migrations apply mabetek-tenders --remote. Секреты Worker задаются через закрытые поля BOT_TOKEN, WEBHOOK_SECRET, AGENT_KEY. Токен Telegram на Mac хранится в связке «Вход» под именем mabetek-tenders.telegram. В случае утраты контролировать того же бота через официальный BotFather, заменить токен Worker и повторно установить webhook с секретом. Ключ агента меняется в Worker и приватной конфигурации Mac одновременно.

Привязка владельца использует одноразовый код с SHA-256 в таблице pairing и expires в секундах UTC; бот принимает /start с этим кодом только в личном чате. В таблице owner может быть одна привязка. Скомпрометированный неиспользованный код следует удалить из pairing. Привязка и изменение ключей требуют доступа администратора проекта.

Конфигурация агента — файл agent.json с правами 0600 в ~/Library/Application Support/mabetek-tenders, поля worker (полный HTTPS-адрес нового Worker), key (отдельный секрет агента), template (путь к утверждённому фирменному PDF). После настройки python3 -m agent.daemon --once проверяет обмен, python3 -m agent.daemon --install устанавливает пользовательский LaunchAgent. После входа в macOS он запускается автоматически. Сбой или сон видны в /status по времени последнего контакта.

Для интеграционного теста нужен tsc в PATH либо переменная TSC с путём к компилятору TypeScript. Команда node --test tests/integration.cjs запускает Worker с локальным SQLite и тестовыми транспортами. Официальные данные Tesseract rus.traineddata и eng.traineddata устанавливаются в .private/tessdata или указываются через TESSDATA_PREFIX. При скане проверяются четыре ориентации страницы. Для выдачи оригинала с фирменной шапкой и подвалом приватный исходник нужен только на Mac.

## Проверенный сценарий в Telegram

В личном чате владельца /status показывает доступность источников и время последнего контакта Mac. Команда /watch со ссылкой на оригинал РЖД создаёт карточку. После ввода условий и сверки суммы кнопка «Сформировать КП» ставит документ в очередь Mac. Статус реальных испытаний и ограничения приведены в reports/status.md.

На подготовленном Mac запустите Install-Mac-Agent.command из папки проекта. При запуске из клона используйте zsh Install-Mac-Agent.command. Установщику нужны фирменный PDF, Python с зависимостями и запись mabetek-tenders.agent в связке ключей текущего пользователя. Установка проверяет соединение с Worker и регистрирует LaunchAgent.

## Обновление облачного обработчика

Publish-Worker.command выполняет обе группы тестов, затем публикует обработчик mabetek-zakupki. Используется обычная авторизация Wrangler для существующего аккаунта. Результат публикации сохраняется в .private/deploy-latest.log. Результаты браузерных проверок приведены в reports/source-coverage.md.

Для смысловой подборки предусмотрен Workers AI binding AI и команда /semantic. Перед включением привязки следует подтвердить Workers Free в аккаунте. До включения модель не вызывается. Миграция 0003 добавляет таблицы для кэша и рейтингов, безопасна для повторного выполнения. Без калибровки на размеченной выборке сходство используется только для просмотра подборки.

Локальная Qwen3-8B-Q4_K_M запускается через llama-completion при анализе приложений на обновлённом агенте. Install-Local-Model.command скачивает контрольный файл с официальной страницы Qwen, сверяет SHA-256 и устанавливает llama.cpp через Homebrew при необходимости. Размер модели 5 027 783 488 байт. Цитаты сверяются посимвольно с извлечённым фрагментом. В отсутствие модели остаётся доступен обычный анализ приложений.

В документах извещения РЖД 32616584495 доступен отдельный Word-бланк технического предложения. После ввода условий откройте «Данные для формы заказчика», затем «Получить черновик формы Word». Бот переносит однозначно указанную процентную ставку. Для другого режима поле остаётся пустым. Если бот использовал ранее проверенную копию, он указывает это в подписи. Отдельные сведения об участнике, персонале и согласия проверяет и оформляет владелец.
