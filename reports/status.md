## Дополнительный прогон
Репозиторий содержит раскрытое дерево исходников. В новой D1 выполнены две SQL-миграции; запрос к sqlite_master вернул 19 таблиц. Дневной счётчик Workers аккаунта в панели при настройке — 150 из 100 000 запросов. Проверка не учитывает будущую нагрузку. Токен сохранён в связке «Вход» на Mac.
Десять тестов Python, четыре модульных теста JavaScript и один интеграционный тест обработчика с SQLite прошли локально. В интеграционном тесте проверены привязка, отказ постороннему пользователю, повтор webhook, заполнение условий, расчёт, кнопка подтверждения, выдача задачи агенту и единственная передача вложения тестовому получателю. Удалённые API в этом тесте заменены.
OCR реально прочитал повёрнутый на 90 градусов русский скан. Город, сумма и числовая площадь извлечены верно. Символ м² распознан неверно. Значения OCR требуют сверки с оригиналом перед выпуском КП. На этом Mac проверены официальные файлы rus.traineddata и eng.traineddata по Git blob SHA.
