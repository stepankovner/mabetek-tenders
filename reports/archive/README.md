# Исходный пул для оценки поиска

20.11.2026 в публичных карточках B2B-Center проверены номер процедуры, заголовок и опубликованная площадкой дата. Поиск проводился по услугам компании, смежным предметам и поставкам оборудования в разных городах. Фактический поисковый запрос включён в каждую строку catalogue.jsonl. Дубли по номеру процедуры исключены. Границы протокола 20.11.2025–19.11.2026; фактические даты найденных карточек 14.01–19.11.2026.

Связь между файлами по полю id. Значение null означает отсутствие извлечённого поля. Время сохранено как на странице. Поле organizer содержит организатора, указанного площадкой. Поисковая фраза и адрес организатора не устанавливают место исполнения.

Единица этого пула — процедура. Один номер может объединять несколько лотов. Реестр не содержит контрольных меток. Период и источник отбора ограничивают переносимость будущей оценки. Контрольные закупки из задания в этот файл не вносились вручную. Перед независимым экспериментом требуются разбивка по лотам, группировка родственных извещений, проверка приложений и заморозка закрытой части по протоколу.

### Проверка номеров лотов по открытым таблицам

Для каждой из 259 процедур запрошена страница «Лоты» на исходной площадке. Для 11 процедур платформа показала таблицы с явными номерами 25 лотов. Для 87 не удалось распознать таблицу, а 161 запрос получил HTTP 302. Проверенное перенаправление ведёт на капчу. Повторный массовый опрос остановлен. Без подтверждённого номера строки не включены в выборки лотов. Сведения об исходе каждой проверки находятся в lot-register.jsonl.

Команда python3 -m agent.archive воспроизводит development.jsonl, held-out.jsonl и unresolved.jsonl и отказывается перезаписывать несовпадающий манифест. Лоты одной процедуры и совпадения организатора и нормализованного названия остаются в одной части. Более сложное родство процедур требует сверки. Этот первый срез слишком мал для заключения о качестве. Новые источники и дополнительные подтверждения должны войти в новую версию среза. Контрольные оценки и ответы независимой модели ещё не собирались.

### Второй срез и независимая сверка

Второй срез объединяет 25 исходных лотов B2B-Center и 20 лотов Росэлторга. Лоты Росэлторга подтверждены на страницах оригиналов по номеру процедуры и лота. Публичные поля записаны в roseltorg-verified.jsonl. После группировки и отсечения по 20.08.2026 получены 30 строк разработки и 15 строк проверки. SHA-256 манифестов v2-development.jsonl и v2-held-out.jsonl соответственно d5b691e3d93f9940ceb414b54c58a6e3805b92e91d9c6238342c6d410963ac47 и 38204a61036b5997f5bbd105191cabfc2fd6706f5083fd397cf4208926beb516.

20.11.2026 те же 15 карточек переданы в новый гостевой сеанс ChatGPT. Интерфейс показывал ChatGPT без версии модели. Запрос и первый ответ сохранены как v2-independent-prompt.txt и v2-independent-response.txt. Второй запрос: «В предыдущем ответе результаты по каждому ID не видны как текст. Выведи ровно 15 строк обычного текста без таблиц или интерактивных элементов. На каждой строке ID | класс | место исполнения | услуга | обязательные условия | чего не хватает | короткая цитата | ссылка». Ответ сохранён в v2-independent-by-id.txt. Сеанс сообщил, что оригиналы по ссылкам не открылись по тайм-ауту. Оценка опиралась на предоставленные публичные поля. Приложения по этим лотам отсутствуют в срезе.

В v2-comparison.jsonl сохранено сопоставление по всем 15 ID. Исходный фильтр заголовков отметил 12. Независимая модель предложила уточнить 2 из этих 12 и отклонила остальные 13 лотов выборки. Обнаружены 10 расхождений. Например, поставка двигателей для перевалочного комплекса попала в подборку из-за слова «перевалка» в наименовании объекта. После этого фильтр доработан. Для независимой оценки новой версии требуется другой, ранее не использованный набор. Это испытание поиска по заголовкам. Живой сбор, срочность, человеческая оценка и полнота поиска среди всех закупок остаются отдельными измерениями.
