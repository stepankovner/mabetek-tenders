20.11.2026 в публичных карточках B2B-Center проверены номер процедуры, заголовок и опубликованная площадкой дата. Поиск проводился по услугам компании, смежным предметам и поставкам оборудования в разных городах. Фактический поисковый запрос включён в каждую строку catalogue.jsonl. Связь между файлами по полю id. Значение null означает отсутствие извлечённого поля. Время сохранено как на странице. Поле organizer содержит организатора, указанного площадкой. Поисковая фраза и адрес организатора не устанавливают место исполнения.

Единица этого пула — процедура. Один номер может объединять несколько лотов. Реестр не содержит контрольных меток. Период и источник отбора ограничивают переносимость будущей оценки. Контрольные закупки из задания в этот файл не вносились вручную. Перед независимым экспериментом требуются разбивка по лотам, группировка родственных извещений, проверка приложений и заморозка закрытой части по протоколу.
